# ONSITE-PROJECT-1-PLANT-DISEASE-DETECTION

ONSITE PROJECT-1

Deep learning-based plant disease classification using the PlantVillage dataset with MobileNetV2 (TensorFlow & PyTorch implementations).

🌿 Plant Disease Detection using Deep Learning

Overview This project implements plant disease classification using transfer learning with MobileNetV2 in both TensorFlow and PyTorch.

The model is trained on the PlantVillage dataset from KAGGLE

Models Used: 

TensorFlow
MobileNetV2 (pretrained on ImageNet)
Loss: Categorical Crossentropy
Optimizer: Adam
PyTorch

MobileNetV2 (pretrained on ImageNet)
Loss: CrossEntropyLoss
Optimizer: Adam
Workflow

Train model
Save trained weights
Load model
Upload leaf image
Predict disease class
Dataset PlantVillage dataset from KAGGLE.

Note: API keys and dataset credentials are excluded for security reasons.
